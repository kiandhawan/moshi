# Data summary

Generated by `scripts/build_datasets.py` from the render manifests. Scripts: `scripts/gen_datasets.sh` = `generate_scripts.py --ordered --unique` (train seed 10, control seed 11 with `--only ordinary --exclude-blocks-from data/scripts/train`, eval seed 12); every set is content-unique (no building block in more than one file of a set; see results/LOG.md); audio: `scripts/render.py` via `scripts/render_all.sh`. Every manifest row in `data/manifests/` records the seed, order_index and generator settings. Fish costs are computed from the text and the cached Moshi clips ($15 per million bytes TTS, $0.36 per hour ASR); a set's cost counts every clip it needs, so subsets overlap (train_1h is part of train_10h; control_10h shares the ordinary files).
